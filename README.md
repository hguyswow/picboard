# 📸 Minos 사진대지 Studio (v2.4.0)

> **"현장 사진대지 작업이 격하게 하기 싫어서 직접 만들었습니다!"**  
> 건설·토목·안전 현장 실무자를 위한 초간편 원클릭 사진대지 자동화 프로그램

---

## 💡 개발 배경
현장에서 사진 찍고 사무실 와서 엑셀 열고, 셀 크기 맞추고, 사진 하나하나 줄이고, 캡션 달고...  
야근을 유발하는 반복적이고 비효율적인 사진대지 정리 작업이 너무나 번거롭고 격하게 하기 싫어서,  
**"사진만 넣으면 관공서 표준 A4 사진대지가 1초 만에 완성되는 도구"**를 직접 개발하여 무료로 배포합니다.

---

## 🚀 주요 기능 및 특징

1. **A4 표준 2단 레이아웃 100% 무결성 보존 (Zero Drift)**
   - A4 1페이지 2장(상/하) 규격 완벽 준수
   - 100장을 넣어도 페이지 밀림이나 여백 왜곡 없이 칼같이 정렬

2. **하단 설명표 1~4개 항목 자유 커스텀 (v2.4.0 신기능)**
   - 1개 선택: 내용 1줄 전폭(100%) 배치
   - 2개 선택: 공종/내용 1줄 50:50 배치
   - 3개 선택: 1행 50:50 (2개) + 2행 전폭 (1개) 공문서 표준 규격 배치
   - 4개 선택: 2x2 표준 4분할 배치
   - **사용자 정의 속성(`custom1`, `custom2`)**: "설계두께", "실측치", "검측부위", "조치사항" 등 원하는 라벨 자유 입력 지원
   - **사진 높이 자동 확장**: 1줄 모드 시 줄어든 표 높이만큼 사진 영역이 상하로 자동 확장되어 전체 A4 여백 100% 보존

3. **현장 날짜 원클릭 스마트 추출**
   - 사진 파일의 EXIF 촬영일시, 파일 수정일, 생성일, 오늘 날짜를 버튼 하나로 자동 기입 및 정렬

4. **실시간 현장 스탬프 합성 (ON/OFF)**
   - 공사명, 공종, 위치, 내용, 일자를 사진 위에 워터마크/스탬프로 선명하게 오버레이
   - 폰트 크기, 투명도, 위치 자유 조절

5. **다양한 출력 및 내보내기 지원**
   - 📕 **관공서 제출용 표준 A4 PDF 출력** (ReportLab 기반 고품질 렌더링)
   - 📊 **원본 셀 서식 보존 엑셀(.xlsx) 출력** (openpyxl 기반)
   - 📦 **스탬프 적용 고해상도 사진 일괄 ZIP 다운로드**
   - 💾 **프로젝트 파일(.picboard) 저장 및 완벽 복원**

6. **3단계 UI 작업 모드 (이지 / 사용자 / 전문가)**
   - **이지 모드 (Easy)**: 초간결 실무 집중 (필수 기능만 노출)
   - **사용자 모드 (Custom)**: 모드 설정(`[⚙️]`)에서 내가 원하는 버튼만 골라서 노출
   - **전문가 모드 (Expert)**: 100% 모든 정밀 편집 기능 노출

## 💻 실행 및 설치 방법

### 1. 일반 사용자 (무설치/원클릭 인스톨)
- `PicBoard_Setup_v2.4.0.exe` 실행 시 관리자 권한 없이 로컬 PC에 1초 만에 설치되며, 바탕화면에 바로가기가 자동 생성됩니다.

### 2. 개발자 / 소스코드 직접 실행
```bash
# 가상환경 구성 및 패키지 설치
pip install fastapi uvicorn pillow openpyxl reportlab

# 웹 스튜디오 개발 서버 실행
python web_launcher.py
# 브라우저 접속: http://localhost:8000
```
