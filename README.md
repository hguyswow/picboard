차가운 컴퓨터 모니터 앞에서 우리를 기다리고 있는 것은 **수백 장의 현장 사진과 끝없는 엑셀 노가다**였습니다.

* *사진 한 장 복사해서 엑셀에 붙여넣고,*

우리가 현장에서 흘린 땀은 부실시공을 막고, 현장 노동자의 생명을 지키며, 안전하고 튼튼한 건축물을 짓기 위한 숭고한 땀방울이었습니다.  
그런 우리가 왜 정작 현장의 품질과 안전에 쏟아야 할 귀중한 에너지를 **'엑셀 표 칸 맞추기'**라는 무의미한 단순 반복에 낭비해야 합니까?  
왜 우리는 사랑하는 가족과 따뜻한 저녁 한 끼를 함께 먹어야 할 시간을 차가운 사무실에서 엑셀과 씨름하며 빼앗겨야 합니까?

퇴근길 셔틀버스 안에서, 붉게 충혈된 눈으로 꾸벅꾸벅 조는 동료들의 지친 어깨를 보며 **정말 격하게 이 작업이 하기 싫어졌습니다.**

> **"사람이 할 일이 아니라면, 컴퓨터가 1초 만에 끝내게 만들자."**  
> **"우리 부장님, 과장님, 기사님들이 제발 오늘 하루만큼은 정시 퇴근하게 만들자."**

그 절박한 마음 하나로 밤을 지새우며 코드를 작성했습니다.  
이 프로그램은 화려한 포트폴리오를 위해 만든 것이 아닙니다.  
**현장에서 함께 흙먼지를 마시는 동료 기술자분들의 저녁 시간을 되찾아드리고 싶었던 한 개발자의 진심 어린 헌정작**입니다.

## 🚀 Minos 사진대지 Studio의 핵심 무기

### 1. 📐 A4 표준 2단 레이아웃 100% 무결성 보존 (Zero Drift)
- 관공서 및 감리단 제출 표준인 **A4 1페이지 2장(상/하 2단)** 규격을 칼같이 준수합니다.
- 10장을 넣든 100장을 넣든, **단 1mm의 페이지 밀림이나 여백 왜곡 없이** 완벽하게 정렬됩니다.

### 2. 📋 하단 설명표 1~4개 항목 자유 커스텀 (v2.4.0 신기능)
- **1개 선택**: 내용 전폭(100%) 배치 (사진 최대화)
- **2개 선택**: 공종/내용 50:50 좌우 균등 배치
- **3개 선택**: 1행 2개(50:50) + 2행 1개(전폭 100%) 관공서 공문서 규격 단정 배치
- **4개 선택**: 공종, 위치, 내용, 일자 2x2 표준 4분할 배치
- **사용자 맞춤 속성**: "설계두께", "실측치", "검측부위", "조치사항" 등 현장에 맞는 자유 라벨 지원
- **사진 높이 역연동 보존**: 칸수(줄)가 줄어들면 줄어든 표 높이만큼 사진 영역이 상하로 자동 확장되어 전체 A4 상하 여백이 100% 불변 유지됩니다.

### 3. 📅 현장 날짜 1초 자동 추출
- 사진 파일 속 메타데이터(EXIF 촬영일자, 파일 수정일, 생성일, 오늘)를 원클릭으로 추출하여 표와 스탬프에 즉시 채워줍니다.
- 날짜순 정렬 시 촬영 순서대로 사진대지가 자동 재배치됩니다.

### 4. 🖨️ 현장 실시간 스탬프 오버레이
- 공사명, 공종, 위치, 상세내용, 촬영일자가 사진 위에 선명하게 합성됩니다.
- 투명도, 폰트 크기, 위치, 라벨 표시 여부를 마우스 클릭 한 번으로 자유롭게 조정할 수 있습니다.

### 5. 📦 다양한 출력 및 내보내기 지원
- 📕 **관공서 제출용 표준 A4 PDF 출력** (ReportLab 고품질 벡터 렌더링)
- 📊 **셀 서식이 완벽 보존된 엑셀(.xlsx) 출력** (수정 및 재편집 100% 호환)
- 📦 **스탬프가 날인된 고해상도 원본 사진 일괄 ZIP 압축 저장**
- 💾 **프로젝트 파일(.picboard) 저장 및 원클릭 복원**

### 6. ⚡ 3단계 맞춤형 작업 모드
- **이지 모드 (Easy Mode)**: 복잡한 기능은 모두 숨기고 핵심 5개 버튼만 노출하는 초간결 실무 집중 모드
- **사용자 모드 (Custom Mode)**: 상단 `[⚙️]` 설정 버튼을 통해 내가 원하는 버튼만 골라서 배치하는 나만의 커스텀 툴바
- **전문가 모드 (Expert Mode)**: 모든 정밀 편집 도구 및 일괄 수정 패널 100% 노출

## 💻 설치 및 실행 안내

### 1. 일반 사용자 (가장 추천 - 1초 원클릭 설치)
- 최신 릴리즈에서 **`PicBoard_Setup_v2.4.0.exe`** 를 다운로드하여 실행하세요.
- 관리자 권한 없이도 안전하게 자동 설치되며, 바탕화면에 **`Minos 사진대지 Studio`** 바로가기가 생성됩니다.

### 2. 개발자 / 소스코드 직접 구동
```bash
# 1. 저장소 복제
git clone https://github.com/hguyswow/picboard.git
cd picboard

# 2. 필수 라이브러리 설치
pip install fastapi uvicorn pillow openpyxl reportlab

# 3. 개발 서버 실행
python web_launcher.py

# 4. 웹 브라우저 접속
# http://localhost:8000
```

## 🛠️ 기술 아키텍처
- **Backend API**: Python 3.12, FastAPI, Uvicorn (비동기 경량 엔진)
- **Frontend**: Modern Vanilla JS (무의존성 순수 자바스크립트), HTML5, CSS3
- **Document Engine**: ReportLab 4.x (A4 PDF 무결성 엔진), OpenPyXL (Excel 엔진), Pillow (이미지 변환 및 스탬프 합성)
- **Packaging & Installer**: PyInstaller (onedir 모드 0.5초 즉시 구동), Inno Setup 6 (LZMA2 Ultra64 초고압축 인스톨러)
