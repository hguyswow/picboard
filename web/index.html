편집 툴바 세부 옵션

Minos 사진대지 Studio 완벽 활용 가이드

1

사진 등록하기 (3가지 방법)

  • [➕ 파일 추가] / [📁 폴더 추가] : 상단 툴바 버튼으로 여러 장의 사진이나 폴더를 한 번에 불러옵니다.
  • 마우스 드래그 앤 드롭 : 윈도우 탐색기에서 사진 또는 폴더를 좌측 사진 목록으로 끌어다 놓으면 즉시 자동 등록됩니다.
  • 클립보드 붙여넣기 (Ctrl+V) : 캡처 도구 등으로 복사한 이미지를 Ctrl+V로 바로 사진대지에 추가할 수 있습니다.
2

사진 내용 입력 및 스탬프 설정

  • 정보표 입력 : 공종, 위치, 표 상세설명을 입력하면 하단 메타 표에 100% 반영됩니다.
  • 현장 스탬프 오버레이 : [스탬프 표시]를 켜면 사진 내부에 일자, 공종, 위치, 내용이 담긴 현장 스탬프가 자동 합성됩니다.
  • 정밀 상세 편집 : 사진을 더블클릭하면 확대 창에서 회전(90°), 여백, 크롭, EXIF 원클릭 날짜 추출을 손쉽게 수행할 수 있습니다.
3

보고서 출력 및 영구 저장

  • [🖨️ 인쇄] (Ctrl+P) : 관공서 표준 A4 세로 2단 양식으로 여백과 비율이 100% 자동 최적화되어 깔끔하게 즉시 인쇄됩니다.
  • [📊 엑셀] : 원본 서식과 동일하게 96% 정밀 배율로 대칭 정렬된 엑셀(.xlsx) 파일로 내보냅니다.
  • [📕 PDF] : 고해상도 벡터 PDF 파일로 즉시 변환 저장합니다.
  • [💾 저장] : 현재 작업 상태 전체를 .picboard 프로젝트 파일로 저장하여 나중에 언제든 원상 복구할 수 있습니다.

상단 중앙의 [⚙️ 모드] 스위처를 통해 작업 목적에 맞는 최적의 화면 모드를 선택할 수 있습니다. 모든 모드 상태는 실시간으로 자동 보존됩니다.

⚡ 이지 모드 (Easy Mode)

초간결 실무 집중 모드: 복잡한 옵션을 모두 숨기고 꼭 필요한 5종 버튼(파일추가, 표 상세설명, 스탬프 표시, 저장, 엑셀, 인쇄, 종료)만 노출합니다. 보고서를 빠르고 직관적으로 작성할 때 가장 추천합니다.

⚙️ 사용자 정의 모드 (Custom Mode)

맞춤형 작업 환경: 모드 옆의 [⚙️] 버튼을 눌러 내가 자주 쓰는 버튼(폴더추가, 붙여넣기, 날짜추출, 프리셋, 회전 등)만 체크하여 나만의 툴바를 구성합니다. 숨겨진 기능도 단축키와 백엔드 데이터는 완벽히 유지됩니다.

🚀 전문가 모드 (Expert Mode)

100% 전체 기능 노출 모드: 프리셋 관리, 4종 날짜 퀵 추출, 여백 슬라이더, 일괄 수정 패널, 프로젝트 열기, 사진 ZIP 내보내기 등 스튜디오의 모든 전문 도구를 한눈에 자유롭게 다룰 수 있습니다.

단축키 / 조작 기능 설명
Ctrl + V 클립보드에 복사된 캡처 이미지를 사진 목록에 즉시 추가
Ctrl + P A4 사진대지 즉시 인쇄 창 호출 (표준 규격 100% 자동 맞춤)
Shift + 사진 클릭 탐색기 스타일로 시작 사진부터 끝 사진까지 구간 연속 다중 선택
사진 더블클릭 해당 사진의 전용 대형 상세 편집창(모달) 즉시 팝업
다중 선택 후 툴바 조작 사진을 2장 이상 체크한 뒤 상단 툴바의 '여백', '회전', '스탬프'를 조작하면 선택된 모든 사진에 실시간 동시 일괄 적용
➖ 빈 페이지 삭제 추가했던 여분의 빈 페이지를 안전하게 원클릭 삭제 (사진이 있는 페이지는 절대 삭제되지 않음)
Q. 인쇄 시 종이 밖으로 표가 삐져나오거나 잘리지 않나요?
A. 전혀 걱정하지 않으셔도 됩니다! 관공서 및 공공기관 제출 표준 양식(A4 세로 2단, 좌우 15mm 여백)에 완벽 호환되도록 1px의 오차도 없이 고정 설계되어 있습니다. 브라우저 인쇄 창에서 배율을 '기본값(100%)' 또는 '페이지에 맞춤'으로 두고 출력하시면 깨끗하게 인쇄됩니다.
Q. 프로그램을 종료하면 작업 모드나 체크박스 설정이 초기화되나요?
A. 초기화되지 않습니다! 브라우저 로컬 저장소(localStorage)와 프로그램 설치 디스크(user_settings.json)에 0.001초 단위로 실시간 2중 저장되므로, 프로그램을 껐다 켜거나 PC를 재부팅해도 직전에 쓰던 모드와 설정 그대로 다시 시작됩니다.
Q. 인터넷이 안 되는 지하 현장이나 오지에서도 사용할 수 있나요?
A. 네! 모든 웹 폰트, 아이콘(FontAwesome), 스타일시트, 파이썬 서버 엔진이 프로그램 내부에 100% 독립 내장되어 있어 인터넷 연결이 완전히 끊긴 오프라인 환경에서도 모든 기능이 완벽하게 동작합니다.
